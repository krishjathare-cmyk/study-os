# Frontend screenshot guide

The README currently uses feature illustrations, not captured UI screenshots.
Capture the real application locally with synthetic data before adding screenshots.

Suggested images (1440 × 1000 or similar, PNG):

1. `preview.png`: open the frontend and show the built-in Preview demo.
2. `study-map.png`: sign in with a test account, create a subject, upload a sample
   PDF, wait for the worker, and show the concept map.
3. `practice.png`: open a subtopic and show practice questions or revision.
4. `lecture-notes.png`: show notes from a synthetic lecture recording.

Use consistent viewport sizes and theme. Hide personal account details, keys,
verification links, and private course material. Store approved captures here and
embed them in `readme.md` with descriptive alt text. Do not present mockups as
screenshots or imply that the public demo exercises live AI services.
